# GitHub Achievements

Repositorio para conseguir los logros de perfil de GitHub que todavía se pueden obtener con acciones reales en la cuenta [arrietaclab](https://github.com/arrietaclab).

Los logros aparecen en la barra lateral del perfil. GitHub puede tardar desde unos minutos hasta un día en mostrarlos.

## Qué se puede hacer desde esta cuenta

| Logro | Cómo se obtiene | En este repo |
| --- | --- | --- |
| Quickdraw | Cerrar un issue o un pull request en los 5 minutos siguientes a abrirlo | Issue abierto y cerrado al momento |
| YOLO | Fusionar un pull request sin revisión | Pull request fusionado sin review |
| Pull Shark | Pull requests fusionados. El primer nivel pide 2 | Dos pull requests fusionados |
| Galaxy Brain | Respuestas aceptadas en Discussions. El primer nivel pide 2 | Dos respuestas marcadas como aceptadas |

## Qué no se puede completar solo

| Logro | Motivo |
| --- | --- |
| Pair Extraordinaire | Hace falta un commit con `Co-authored-by` de otra persona y que ese pull request se fusione. GitHub permite una cuenta personal por persona; no se usa una segunda cuenta para fabricar el logro. |
| Starstruck | El primer nivel pide 16 estrellas de otras personas en un repositorio que hayas creado. |
| Public Sponsor | Hay que patrocinar a alguien con GitHub Sponsors. Eso implica un pago. |
| Arctic Code Vault Contributor | El archivo de febrero de 2020 ya está cerrado. |
| Mars 2020 Helicopter Contributor | Solo contó el código usado en esa misión. |
| Heart On Your Sleeve y Open Sourcerer | GitHub los dejó en pausa y hoy no se otorgan. |

## Niveles siguientes

- Galaxy Brain: 2, 8, 16 y 32 respuestas aceptadas.
- Pair Extraordinaire: 1, 10, 24 y 48 commits en coautoría fusionados.
- Starstruck: 16, 128, 512 y 4096 estrellas.
